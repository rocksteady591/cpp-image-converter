# 🖼️ Image Library — кросс-платформенная библиотека для работы с изображениями

## 📖 О проекте

**Image Library** — это лёгкая, модульная библиотека на **C++17** для загрузки, сохранения и конвертации изображений в форматах **PPM**, **JPEG** и **BMP**. Проект реализован с нуля без использования сторонних высокоуровневых библиотек (кроме **LibJPEG** для работы с JPEG) и демонстрирует глубокое понимание форматов файлов, побайтовой работы с данными и принципов ООП.

Библиотека предоставляет унифицированный интерфейс для всех поддерживаемых форматов, что позволяет легко расширять её новыми типами файлов.

---

## ✨ Возможности

- **Загрузка и сохранение** изображений в форматах:
  - **PPM** (Portable Pixmap) — простой текстово-бинарный формат для отладки.
  - **JPEG** — популярный формат сжатия с потерями (используется LibJPEG).
  - **BMP** (Windows Bitmap) — классический растровый формат без сжатия.
- **Конвертация** между форматами одной командой.
- **Единый внутренний формат** — все изображения приводятся к RGB с 8 битами на канал.
- **Интерфейс на основе стратегии** — каждый формат реализует общий интерфейс `ImageFormatInterface`, что упрощает добавление новых форматов.
- **Кроссплатформенность** — работает на Windows, Linux и macOS.
